# spirit-basketball

로그인 없이 링크만으로 볼 수 있는 농구 전술 공유 페이지입니다.

- 메인 화면에서 전술 목록을 확인합니다.
- 전술을 클릭하면 농구 코트(SVG) 위에서 선수 위치(O)가 화살표 경로를 따라 움직이는
  애니메이션으로 전술을 확인할 수 있습니다.
- 별도의 빌드 과정이나 서버, 로그인이 필요 없는 순수 정적 사이트입니다.

## 로컬에서 실행하기

빌드 도구가 필요 없습니다. 정적 파일을 아무 HTTP 서버로 서빙하면 됩니다.

```bash
npx serve .
# 또는
python3 -m http.server 8080
```

이후 브라우저에서 `http://localhost:8080` 접속 (포트는 사용한 서버에 맞게 조정).

## 배포

정적 파일(`index.html`, `css/`, `js/`)만 있으면 되므로 GitHub Pages, Netlify, Vercel 등
어떤 정적 호스팅에도 그대로 올리면 됩니다. 로그인 기능이 없으므로 배포된 링크를 아는
누구나 바로 접근할 수 있습니다.

## 검토 기록

- [`docs/stat-sheet-omr.md`](docs/stat-sheet-omr.md) — 수기 기록지를 마킹(OMR) 방식으로 바꾸고
  사진을 올리면 엑셀이 나오게 하려는 계획. **검토만 끝났고 아직 만들지 않았다.**
  실측 숫자와 결정 근거가 들어 있으니, 제작에 착수할 때 여기서 이어서 시작하면 된다.

## 전술 추가하기

`js/data.js`의 `TACTICS` 배열에 새 항목을 추가하면 됩니다. 각 선수(`players`)는
`path`(웨이포인트 좌표 배열)를 가지며, 좌표가 1개면 고정 위치, 2개 이상이면 해당 경로를
따라 애니메이션으로 이동합니다. 좌표계는 하프코트 SVG 기준(`viewBox 0 0 500 470`, 골대는
`(250, 442)` 부근)입니다.
